# Word knowledge keeps every word entry

We keep every word entry instead of only the last few, because the learned and hard-word rules need days and question types, and the cost is small: about 220 KB per typical pupil per school year. The one real limit is the server's 2 MB ceiling on a pupil's progress, which a very keen pupil could reach in 2–3 years, so the history cap is a single constant (no limit today) and the server reports the largest progress file long before the ceiling is near (#44).
