# requirements.txt says WHICH grammar libraries the data is built with and is
# what a person installs by hand. This file pins the whole set — the three
# libraries and everything they pull in — to exact files by their SHA-256, for
# CPython 3.13 on x86_64 Linux, the platform the committed data was built on.
# `pip install --require-hashes --only-binary=:all:` installs exactly these
# bytes or stops; nothing is compiled, so no compiler can change a parse.
#
# Why the platform is part of the pin: with the very same versions, a build
# on an ARM Linux VM (where pip compiles reynir's parser from source, because
# no ARM wheel exists) parsed one token differently from this x86_64 wheel —
# see the commit "chore: accept the Linux-container parse baseline".
#
# Changing a line here is changing the grammar the data is built with: do it
# together with requirements.txt, run ./build-in-container.sh, and read the
# parse-diff before `--accept` (CLAUDE.md).
#
# Hashes taken from PyPI with `pip download --only-binary=:all:
#   --python-version 3.13 --platform manylinux_2_28_x86_64 …` and sha256sum.
